## Entry

> My smart fridge's ice maker has two settings: avalanche, and one single cube it clearly resents making.

## How it works

`main.py` writes that single line (103 characters, no trailing newline)
to `<output_dir>/entry.txt`. The entry is fixed text, so the output is
fully deterministic — the same bytes on every run.

## Why this roast

The joke targets the ice maker, one of the most fridge-specific parts of
a smart fridge, and avoids the obvious cracks about ordering groceries or
watching the owner. Instead, the ice maker behaves like a resentful
employee with exactly two moods: a full avalanche, or a single cube handed
over grudgingly.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
